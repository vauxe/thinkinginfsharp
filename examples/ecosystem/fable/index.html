Fable browser boundary

Fable compiles App.fs into JavaScript. The browser executes that JavaScript; it does not host the .NET runtime.

What crosses the boundary?
  • The model, union messages, and update are ordinary pure F#.
  • Browser.Dom supplies typed bindings to browser APIs such as events and elements.
  • Only APIs supported by Fable or a compatible binding are available; arbitrary .NET libraries are not.
